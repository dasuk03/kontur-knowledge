# КОНТУР — база знаний специалиста учёта

Интерактивная база знаний для адаптации электромонтёров и специалистов ИСУЭ/АСКУЭ: персональный маршрут, полный каталог материалов, диагностический поиск, практические ситуации, атлас оборудования и локальный кабинет наставника.

## Возможности

- персональный маршрут по роли, опыту и цели;
- локальное сохранение прогресса без регистрации;
- три режима статьи: «За 1 минуту», «Изучить», «На объекте»;
- диагностические подсказки по рабочим формулировкам;
- интерактивные практические кейсы с объяснением решений;
- карточки оборудования со связанными статьями и документами;
- отчёт для наставника и печатный итоговый лист;
- мобильный полевой режим и офлайн-кэш приложения;
- 131 статья и 60 первичных источников в едином поисковом индексе.

КОНТУР не заменяет инструктаж, наряд-допуск, распоряжение, оперативный журнал, проверку знаний и официальные допуски работодателя.

## Локальный запуск

Требуется Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm run lint
npm test
```

## Добавление документов

Необработанные PDF/DOCX помещаются в локальную папку `incoming/`, которая исключена из Git. После полного чтения содержание распределяется по существующим модулям статей, связывается с записью источника и проверяется по правилам из `CONTENT_INGESTION.md`.

Репозиторий публичный: исходные документы, секреты, персональные данные и служебная информация не должны попадать в коммиты без отдельного разрешения на публикацию.
